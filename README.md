# JRDspace Blog

Personal blog of Janaki Rajesh.D, built with Jekyll + Chirpy.

## Live Site

- https://jrdspace.github.io/jrdspace-blog/

## Content

- Posts are in `_posts/`
- Tabs/pages are in `_tabs/`
- Images are in `assets/img/posts/`

## Local Run

```powershell
cd D:\jr-blog
bundle exec jekyll s --host 127.0.0.1 --port 4000
```

Open: http://127.0.0.1:4000
